# ELG One – Download

ELG One ist die Arbeitsoberfläche von [ELG Solutions](https://elgsolutions.at) für Claude und Codex.
Hier liegen nur die Installationsdateien. Ein Zugang zu ELG One kommt von ELG Solutions.

## Herunterladen

| System | Datei |
| --- | --- |
| **Windows** (64 Bit) | [ELG-One-Setup.exe](https://github.com/elgsolutions/elg-one-download/releases/download/stabil/ELG-One-Setup.exe) |
| **macOS** (Apple-Chip M1 und neuer) | [ELG-One-mac.dmg](https://github.com/elgsolutions/elg-one-download/releases/download/stabil/ELG-One-mac.dmg) |

Die Links zeigen immer auf die aktuelle Version. Danach aktualisiert sich ELG One von selbst.

## Installieren

**Windows:** `ELG-One-Setup.exe` doppelklicken. Erscheint „Der Computer wurde durch Windows geschützt“,
auf **Weitere Informationen** und dann **Trotzdem ausführen** klicken. Administratorrechte sind nicht nötig.

**macOS:** `ELG-One-mac.dmg` öffnen und ELG One in den Ordner „Programme“ ziehen. Meldet macOS beim ersten Start,
dass die App nicht geöffnet werden kann: Systemeinstellungen → Datenschutz & Sicherheit → **Trotzdem öffnen**.
